# Flamingo Travel Tracker - Design Recreation

This project recreates the exact design of the Flamingo travel tracker application as shown in the provided screenshot.

## Features Recreated

- **Orange gradient background** matching the original design
- **Central download card** with dark theme and prominent call-to-action
- **Step-by-step guide cards** (02-05) explaining the app functionality
- **Information cards** for Important Notifications and Complete Privacy
- **Tax Residency card** with dark theme
- **Mobile phone mockups** showing the app interface
- **Features section** with Visa-Free Stay, Residence Status, and Download Reports
- **Expats and Residents card** with profile section
- **International Students card** with student information
- **Responsive design** that adapts to different screen sizes

## Design Elements

- **Color Scheme**: Orange gradient (#FF9B47 to #FFC085) background with white and dark cards
- **Typography**: Modern sans-serif fonts with proper hierarchy
- **Layout**: CSS Grid-based responsive layout
- **Cards**: Rounded corners with subtle shadows
- **Buttons**: Orange call-to-action buttons with hover effects
- **Icons**: Consistent icon styling throughout

## Files

- `index.html` - Complete HTML structure
- `styles.css` - Comprehensive CSS styling
- `README.md` - This documentation file

## How to View

1. Open a web browser
2. Navigate to `http://localhost:8000` (if server is running)
3. Or simply open `index.html` directly in your browser

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Gradients)
- Responsive Design
- Modern CSS features

The design perfectly matches the original Flamingo screenshot with all visual elements, layout, colors, and styling faithfully recreated.
